# AI Drama IDE Lite v0.2.62

这版解决流水线等待子任务卡住、有声镜头合成后丢失配音的问题，并包含项目提示词配置与免费新手教程。

## 修复

- 项目与按集流水线可以顺序执行自己排队的图片、视频及审核子任务，避免父任务占用 Worker 后一直等待。
- 暂停与恢复沿用已有子任务和已提交的远程任务 ID；取消停止本地轮询和后续提交，Worker 停止时保留可恢复状态。未支持远程取消的服务商可能仍在处理已提交任务。
- 场景合成优先使用当前镜头对应的配音视频，声音会继续保留到分集合成；没有配音的镜头使用原视频。
- 配音记录源视频版本，合成遇到旧视频的配音时明确提示重新配音，防止新画面混入旧对白。兼容此前未记录源版本的配音素材。

## 新功能

- 在「设置 → 项目提示词」自定义小说、故事分析、剧本、分镜、资产、图片、视频及审核环节的创作规则；按项目保存，支持默认规则恢复和随项目导入 / 导出。
- 顶部「设置」旁新增「教程」，以高亮引导完成创作与合成，包含「选择哪些参考资产」的操作。
- 教程使用预制《末班灯火》小说、Story Bible、剧本、参考图和 20 秒无声短片，不调用用户的 AI API，也不改动用户项目。

## 安装与更新

- Windows x64：下载 `ai-drama-ide-lite-windows-x86_64-setup.exe`。
- macOS Apple Silicon：下载 `ai-drama-ide-lite-macos-aarch64.dmg`。
- 已安装用户可通过「设置 → 检查更新」更新；正常更新保留本机项目和模型配置。
- 版本号采用 `0.2.62`，以兼容此前发布的 `0.2.61` 的升级比较。

Windows 尚未提供代码签名，macOS 沿用 ad-hoc 签名与现有安装方式。真实服务商的生成速度、产量与费用没有在本次发布中实测；本次验证没有调用付费 AI API。
