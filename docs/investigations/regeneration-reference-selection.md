# 重新生成的版本化参考图

## 已交付

- 分镜关键帧与视频生成现在可传递精确的 `reference_version_ids`，不再只能取资产当前版本。
- 视频可传递 `source_image_version_id`，明确锁定所用关键帧版本。
- 每个新结果记录实际的参考版本、用户提示词和 `regenerated_from_version_id`。
- 生产依赖边记录上游版本号，供后续失效检测使用。
- 资产页不再直接批量提交关键帧任务；受影响镜头需在分镜页逐一确认后创建。

## 兼容规则

- 旧客户端继续使用 `reference_asset_ids`，服务端解析资产当前版本。
- 新客户端使用 `reference_version_ids`；两个字段同时出现会被拒绝，避免静默覆盖用户选择。
- 历史输出没有完整来源记录时，分镜页退回镜头自动匹配，并允许用户重新选择。

## 当前 UI 流程

1. 在分镜详情选择角色、场景、道具或导入参考图。
2. 对故事资产点击“选择历史版本”，指定 v1、v2 或当前版本。
3. 生成视频前选择具体源关键帧版本。
4. 点击“重新配置并生成图片/视频”才创建新的 Job；旧版本保持可恢复。

## 后续边界

- 导入的外部参考图当前只有导入版本；需要支持外部图多版本编辑时，再扩展其版本管理接口。
- 资产影响范围已经禁止自动付费批量生成；下一步可加入“逐个配置队列”，但不应提供默认的一键套用。
