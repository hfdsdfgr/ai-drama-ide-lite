# 离线新手教程计划

日期：2026-10-02。

## 用户路径

1. 顶部设置按钮旁新增「教程」，随时打开；不要求已选择项目或配置 Provider。
2. 打开独立的免费练习区，原项目、当前页面及未保存编辑保持挂载和原状态。
3. 跟随教练面板，点击当前高亮的导航 / 操作：创建示例项目 → 导入小说 → 分析 Story Bible → 生成并保存剧本 → 生成参考资产 → 生成分镜 → 勾选并确认镜头参考资产 → 图片 / 视频 → 本集预检 → 合成与播放。
4. 所有内容来自本地《末班灯火》模板，操作立即显示预置结果，明确标注「示例」。不模拟网络等待或伪造生成进度。
5. 允许上一步、从头练习、完成或随时退出。退出恢复原界面焦点，不写入用户项目；最终展示真实创作的操作顺序和费用边界。

## 推荐实现与取舍

教程以原生 `<dialog>` 覆盖现有 App，内部沿用模块顺序、配色和内容 / 操作布局，使用前端内存状态与内置素材。相较于向用户数据库植入教程项目或全局拦截 API，这个方案避免污染用户数据、误改现有项目、后台任务并发和付费调用边界漏洞。首版练习控件专用于教程，不接入实际生成服务；不增加依赖，不重构已有页面。

步骤数据声明当前模块、目标元素、讲解和进入条件。点击目标才推进操作步骤；阅读步骤提供继续按钮。SVG 遮罩与目标边框形成聚焦高亮，随窗口大小、滚动和布局变化更新；教练面板和退出入口保持可用。步骤计数反映实际操作完成，不作为生成百分比。

资产选择练习沿用实际分镜页的复选框：镜头 1 需要林晚和青岚站，未选全或多选时提示原因并禁止确认。其余镜头使用模板自带的引用；上一步保留勾选，从头练习清空勾选。只在内存保存，不调用 API。

## 素材

原创短故事《末班灯火》：林晚在雨夜赶到即将停运的青岚站，陈叔将父亲留下的车票和信交给她；她选择留下陪他守完最后一班车。

预置一章小说、两个人物、一个地点、一个道具、一个场景剧本和四个五秒镜头。参考图和分镜为本地绘制的 SVG 插画；镜头视频与 20 秒分集视频使用已有本地浏览器 / FFmpeg 离线制作并打包。示例视频无声，不声称来自 AI Provider。教程运行时不需要构建工具或网络生成服务。

## 调研依据

- [MDN showModal](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal)：原生模态使同一文档的其他内容不可交互，适合保护背景编辑。
- [W3C Dialog Modal Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) 与 [H102](https://www.w3.org/WAI/WCAG22/Techniques/html/H102)：模态保持内部焦点，Escape 退出，退出后恢复入口焦点。
- 复用已有 React / TypeScript、设计 Token、`Stepper` 和本地验收 Playwright；不引入 tour 框架或状态管理库。

## 验证

类型检查、Lint、现有前端测试与构建；验证步骤推进约束、边界和素材一致性。浏览器走完整教程，拒绝 / 记录所有教程期间的网络生成请求，确认无数据库 / Job 写操作、当前项目与草稿保持、关闭 / Escape / 重开和键盘焦点正常；检查高亮在滚动、1440px / 900px 和窄窗口中的位置，以及视频实际可播放、无裁切或横向溢出。所有检查不调用用户付费 API。
