# Phase 24 M4 参数 Schema 子集实施报告

日期：2026-09-11

状态：本轮已完成参数 Schema 子集；M4 的 CLI / Agent 入口仍未实施。

## 本轮交付

- Adapter 基类提供统一的参数描述与校验协议，控件只使用项目白名单字段。
- Sora、智谱、百炼、火山方舟返回已经在调用链中验证过的图片比例、视频规格或时长选项；模型差异由 Adapter 决定。
- OpenRouter、SiliconFlow 没有被强行抽象出跨模型统一档位，避免 UI 选项与真实上游能力不一致。
- 增加 `GET /api/models/{model_id}/generation-schema` 与参数校验接口；响应不包含 API Key、Provider URL、请求头或厂商原始请求体。
- `GenerationService` 和图片任务创建前复用 Adapter 校验器。非法的已声明参数会在 Job 落库前失败，因此不会产生排队任务或费用动作。
- 剧集工作流和分镜视频配置使用通用动态控件。切换模型时保留旧值但明确标记失效；用户必须逐项重新选择，不能静默替换。

## 用户收益

模型选择、参数选择和提交前校验现在遵循同一套服务端规则。用户不会看到模型无法处理的固定时长，也不会因为切换模型而悄悄改变原配置；过期配置会在保存 / 生成前被明确拦截。对 AI 漫剧而言，这减少了批量制作中途才发现参数不兼容、批次被供应商拒绝和重复付费重试的风险。

## 明确边界

- 本轮不扩展音频能力。
- 未验证的聚合 Provider 参数不展示可选值；已有旧配置会保留并提示用户处理。
- 资产页的业务画幅仍由资产类型规格决定，没有让模型 Schema 覆盖资产设计规则。
- CLI / Agent 入口、付费确认门槛、M3 Prompt Patch / 情绪 / blocking 均未在本轮继续实施。
