# 调研：小说创作界面布局（NovelPage 重排依据）

> 调研时间：2026-08-13。规则 75（Research Before Every Step）。

## 结论

成熟小说写作工具的界面高度一致，都是**三栏工作台**：

1. **左栏 = 结构导航**：书籍/章节树状管理（Scrivener Binder、NovelCrafter 大纲、
   诗成写作左栏、CharacterArc 目录树）。
2. **中栏 = 正文编辑**：沉浸式编辑器，附带保存状态与 AI 操作入口。
3. **右栏 = 灵感/设定/AI 助手**：Codex / 设定 / 灵感 / AI 侧边栏
   （NovelCrafter Codex、SuperNovelist 右侧 AI 助手、CharacterArc AI 侧边栏）。

## 对 NovelPage 的影响

- 顶部工具栏：项目选择 + 搜索 + 新建/导入小说
- 左栏：小说列表 + 章节树
- 中栏：章节标题 + 只读正文 + AI 创作（续写/扩写/重写）工具栏 + 结果预览
- 右栏：标签页切换「AI 撰写」向导 /「Story Bible」
