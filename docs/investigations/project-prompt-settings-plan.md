# 项目级提示词自定义实施计划

日期：2026-10-02。

## 目标与边界

用户可以按项目查看、替换并保存各生产环节的创作规则，恢复内置默认规则，并免费预览规则组装结果。现有单次生成要求、角色参考描述和镜头内容继续作为生成输入。输出 JSON / 正文格式和输入内容作为数据的约束独立保留。

覆盖小说大纲、章节与续写 / 扩写 / 重写，故事抽取与合并，剧本、分镜、资产卡补全，角色 / 场景 / 道具 / 分镜图片，镜头视频，以及已有视觉 / 剧情 / 台词审核。内部 JSON 修复、厂商协议和旧音频台词归属工具不作为用户创作环节开放。

本次不加入跨项目全局预设、角色 Prompt Patch、导演情绪 / Pose 控制、自动重生成或新的模型调用。

## 实施顺序

1. 将默认创作规则与不可编辑的输出契约放入独立目录表，新增项目配置存储和严格 API。配置采用修订号保护，显式区分恢复默认与清空媒体约束 / 负向词。
2. 文本服务与媒体生成服务共用配置解析；单次请求在操作开始时读取，后台任务与流水线保存提示词配置快照。暂停恢复与同任务重试沿用快照。
3. 在现有设置页添加当前项目提示词编辑入口，提供保存、放弃修改、恢复默认、规则预览及明确的加载 / 错误 / 冲突状态。
4. 增量扩展项目导入导出，旧项目包无配置时使用默认；不覆盖已有内容，不重建数据库。
5. Mock 验证请求最终使用自定义规则、旧规则不会再次追加，格式契约保留，项目隔离、修订冲突、空值语义、流水线快照与迁移兼容；运行后端 / 前端测试、类型检查、lint、构建和可行的浏览器验证。

## 主要影响

- 后端：新增 Prompt Catalog / Settings Service、Schema / API 和 `project_prompt_settings` 表；生成、审核、Job / Pipeline、项目 transfer 接入。
- 前端：设置页项目上下文、提示词编辑组件与 API。
- 文档：使用说明、Roadmap 与实施结果。

## 风险与验收

- 创作规则不能删除结构化输出契约；不因用户正文中的指令改变系统规则。
- 自定义规则不与内置创作规则重复叠加；用户参考内容不得隐式修改。
- 预览不调用 Provider，也不创建 Job。标明这是规则层预览，实际内容在生成时注入。
- 运行中更改配置不改变已启动任务的规则；新任务读取最新配置。
- 旧数据库 / 旧项目包可读取，配置随项目导出导入，密钥不进入配置或日志。
- 实际生成质量依赖用户模型；本次验证使用 mock，不产生外部 API 费用。
